## Step 7 — the `closed` clause

Two states, like `ci` and `merge`. The ordinary one is an issue GitHub has not closed yet. The other
is a **permanent deadlock of the same shape as `merge`'s**: `machine.ts:178-181`'s `closedByMerge`
requires `task.merged_at_ms !== null`, and the *only* writer of that field is the `merge → close`
edge (`machine.ts:168`; `cli.ts:114` initialises it to `null`). `cmdRewind` sets
